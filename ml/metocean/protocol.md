# Metocean experiment, 2026-09-26

Protocol fixed before fitting or evaluating new models.

Archive routing: 2014–2015 expt_53.X; January–April 2016 expt_56.3; May 2016–January 2017 expt_57.2; 2018 GLBv expt_93.0; from December 2018 GLBy expt_93.0. Coverage failures are retried against the correct documented archive, never substituted with another date.

Download ERA5 10 m wind, ERA5-Ocean waves through Open-Meteo and HYCOM GOFS surface currents (0 m). For Black Sea 2024 field records request SMOC via Open-Meteo; missing sea cells remain missing. Save exact requests, original responses, SHA256, returned grid coordinates and time coverage. ERA5 0.25°, ERA5-Ocean 0.5°, HYCOM nominal 0.08° are environmental context, not 10 m measurements. Open-Meteo data CC BY 4.0; free endpoint used for this research experiment; commercial API usage has separate terms. HYCOM catalogue: freely available; retain attribution to HYCOM/NRL/FNMOC.

Enrich all 318 registry events and the existing 190 paired L2A patches. Preserve original case data and prior models. Patch time comes from its matched STAC acquisition datetime. Field events use known UTC start; dates without time get daily summaries only and never acquire fabricated observation times. Event coordinate is representative, not a reconstructed track. Use all available original source fields for provenance; do not derive new labels from environmental models. EMBLAS without coordinates cannot be joined. Unlabelled Black Sea reserved holdout remains untouched.

Features: latest model timestep at/before observation and trailing 24/72 h means of wind speed, east/north wind components, wave height/period/direction sine/cosine, east/north current and current speed. Wind/wave directions use meteorological FROM convention; HYCOM components are TO. No future timestamps in instantaneous or trailing features. Require 75% expected temporal coverage for trailing summaries. Hourly age <=1 h, HYCOM age <=3 h. HYCOM nearest valid sea cell within 15 km using a small surrounding box; report displacement; ERA5-Ocean sea displacement <=60 km, ERA5 <=40 km. This is retrospective reanalysis, not an operational forecast benchmark.

Primary pixel experiment uses identical existing train/val/test groups and pixels. RF parameters as previous experiment (125 trees, depth20, leaf2, balanced_subsample, seed42, 4 jobs); confidence weights unchanged. Fixed variants: spectral baseline, spectral+wind, spectral+waves, spectral+currents, spectral+all, environmental-only diagnostic. Missing covariates: median+indicator fitted on TRAIN patches only, never on repeated test pixels; all-missing training columns excluded and documented. Set max_features=3 for every spectral RF (same number of candidate variables as prior 11-band RF) to limit feature-count confounding; env-only also max_features=3. No latitude/date/IDs as pixel predictors. No parameter tuning after test. Choose threshold by max F1 on validation only, freeze models/thresholds before test. Compare same test pixels; paired bootstrap whole existing groups (1000, seed42). Report AP/precision/recall/F1, class errors, group metrics, high-confidence labels and >100 km from train slice. Development test has already been inspected; new external Black Sea truth still required.

Secondary field concentration experiment: reuse prior selected event rows, measurement profiles and exact grouped CV memberships from reports/eda. Never pool measurement profiles. Fixed RF regression on log1p density (125 trees, depth8, leaf3, max_features=1.0, seed42): location+season control versus same+environment; environment-only diagnostic, train median. Imputation fitted separately on fold train. Evaluate OOF MAE/RMSE/RMSLE/R² and whole-group paired MAE bootstrap. This is field context regression, not pixel classification or a new satellite-density calibration. Target-derived fields/counts/areas never predictors. No choosing a deployed model by these exploratory results.

EDA: coverage by source/split, missingness, physical ranges/units, time/grid displacement, distribution shift, feature correlations at patch/event grain (not duplicated pixels), within-profile association with concentration, observed wind versus reanalysis, model metrics and errors. Preserve raw and enriched tables; explicit missing values and provenance.
