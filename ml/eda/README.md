# EDA макропластика

Основной результат — [выполненный notebook](../../notebooks/01_macroplastic_eda.ipynb).
Для просмотра без Jupyter: [HTML](../../reports/eda/macroplastic_eda.html).
Краткий отчёт: [выводы](../../reports/eda/conclusions.md).

Анализ охватывает исходный CSV, README, оба PDF из `docs/descriptions`, конфигурацию
отбора, сохранённые реестры наблюдений/сцен и фактическое наличие внешних данных.
Сеть не требуется. Исходники и реестры не меняются.

## Повторный запуск

Из корня репозитория, Python 3.12:

```bash
uv venv ml/.venv --python 3.12
uv pip sync --python ml/.venv/bin/python ml/eda/requirements.lock.txt
ml/.venv/bin/python ml/eda/run.py
```

Без `uv` можно создать venv через `python3.12 -m venv ml/.venv` и установить
зависимости через `ml/.venv/bin/python -m pip install -r ml/eda/requirements.lock.txt`.
Установка требует сети, выполнение анализа — нет. GPU не нужен; после установки
библиотек полный расчёт в текущем окружении занимает около 10 секунд.

`macroplastic_eda.py` — читаемый исходник в формате `# %%` с кодом и Markdown.
Правки вносить в него: `run.py` пересоздаёт notebook, запускает все ячейки отдельным
ядром из текущего Python, сохраняет результаты и экспортирует HTML.
При ошибке выполнение прерывается; notebook с ошибкой сохраняется для диагностики.
Существующий HTML в этом случае не обновляется, поэтому проверяйте успешный exit code.
Для ручного выполнения notebook в IDE выберите интерпретатор `ml/.venv/bin/python`.

## Результаты

- `reports/eda/conclusions.md` — выводы и порядок следующих экспериментов.
- `reports/eda/summary.json` — основные числа и ограничения.
- `reports/eda/tables/baseline_metrics.csv` — MAE, RMSE, R², RMSLE и интервалы MAE.
- `reports/eda/tables/oof_predictions.csv` — все эталоны и прогнозы трёх baselines.
- `reports/eda/tables/cv_memberships.csv` — состав train/test каждого fold, event/sample/scene IDs.
- `reports/eda/tables/split_integrity.csv` — проверки пересечений и близости.
- `reports/eda/tables/accepted_pairs_audit.csv` — качество, геометрия, время и сценарный дрейф.
- `reports/eda/tables/input_hashes.csv`, `run_info.json` — входы, SHA-256, версии и параметры.
- `reports/eda/figures/` — графики для повторного использования.

Параметры группировки, kNN и bootstrap заданы в `config.toml`. Цели и допуски N/A
читаются из `backend/config/case.toml`; EDA независимо повторяет отбор и сверяет реестры.
Метрики можно пересчитать из сохранённых OOF-ответов без обучения.

## Границы эксперимента

Grouped CV — исследовательская проверка полевой пространственной модели по четырём
отдельным профилям. Это не финальный внешний test и не проверка переноса концентрации
на спутниковый снимок. Данные всех полевых событий уже просмотрены в EDA.
Правило 50 км / 3 дня уменьшает зависимость, но требует проверки по полной геометрии;
чувствительность числа групп к порогам сохранена отдельно.

Для вычисления метрик детектора нужны реальные спутниковые изображения и маски.
В этом checkout их нет; манифесты загрузок не считаются изображениями.
Метрики детектора и спутниковой концентрации помечены `null`, а не нулями.
