# L2A: обучение и калибровка, 26.09.2026

Протокол до нового обучения/метрик. Веса прежних моделей и case CSV не меняются.

1. Сопоставить все MARIDA сцены с Earth Search sentinel-2-c1-l2a по уникальному MGRS/date/footprint. Не подменять дату; missing/ambiguous сохранить. Это перенос существующей пиксельной разметки на повторно обработанную съёмку, не новая независимая разметка.
2. Сохранить строгие MARIDA split/group без перемешивания пикселей между частями. До загрузки/инференса зафиксировать максимум 6 патчей каждой доступной сцены: до 3 с наибольшим числом debris; далее фон с максимальным покрытием ещё не представленных отрицательных классов (tie: сумма sqrt(count), затем patch ID). Это выборка, обогащённая редкими классами; её метрики не описывают естественную встречаемость мусора.
3. 11 каналов, исходная MARIDA grid, nearest neighbour, asset scale/offset, invalid/nodata исключить. Только label>0, confidence>0, все каналы обоих продуктов валидны. SCL water не становится отрицательной меткой; облака/пена/суда остаются своим размеченным фоном. Пропусков не заполнять. Каждый STAC product и group принадлежит только одному split.
4. Заранее фиксированные сравнения:
   - прежний MARIDA RF и joint RF с исходными порогами;
   - те же веса с порогами, выбранными только по L2A validation;
   - новый RF на L2A train, порог по L2A validation (основной кандидат);
   - контроль: новый RF на rhorc ровно тех же train-пикселей, порог также по L2A validation. Контроль отделяет целевой продукт от размера обучающей выборки.
5. RF: 125 деревьев, max_depth20, min_samples_leaf2, balanced_subsample, seed42, n_jobs4. Confidence weights: 1, 2/3, 1/3. Поиск гиперпараметров и выбор вариантов после test не проводить. Максимум F1 на validation, при равенстве больший порог. Сохранить validation scores, модели и пороги ДО test inference. Минимум две группы с debris в train/val/test и оба бинарных класса; иначе эксперимент считать недостаточным.
6. Test: одинаковые пиксели для всех моделей. Precision/recall/F1/IoU/AP, исходные классы, confidence=1 отдельно, paired bootstrap 1000 повторов целыми группами, seed42. Основные contrasts: новый L2A RF минус исходный joint; минус joint с L2A-порогом; минус парный rhorc-контроль. Нельзя считать эффект перенастройки порога эффектом обучения.
7. Старый MARIDA test уже использован в разработке: это development benchmark, не новый внешний тест. Дополнительно описать покрытие мест/дат и расстояние test-патчей до train; общий регион в разные даты не считать географической независимостью. Неизвестные пересечения MADOS/MARIDA ограничивают joint comparison.
8. 12 неразмеченных Black Sea reserved_holdout не включать в train/validation/test и не запускать на них модели. Для них нужна независимая экспертная разметка. Никаких новых меток из DOORS Rrs/CTD/неподтверждённых времён. Результат не является оценкой концентрации items/km² или региональной точности Чёрного моря.

## Поправка до обучения и метрик

Проверка исходных class counts после выбора обнаружила 0 Foam в train. В доступных train-сценах всего один патч с Foam: 4-9-19_16PCC_32 (18 пикселей). Он добавлен как исключение из лимита шести патчей, только в train, до запуска обучения/test inference. Итого 190 патчей. Validation/test не меняются. Исходный выбор сохранён в selection_initial_189.csv. Причина поправки — покрытие отрицательного класса; модельные scores при решении не вычислялись.
