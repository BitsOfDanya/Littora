# Протокол расширения (зафиксирован до обучения и просмотра MADOS scores)

Источники: MADOS v1 (Zenodo 10664073), PLP2019 (Zenodo 3752719), supplementary Table S2 González-Fernández 2022. Исходный case CSV и production-модели не меняются.

## MADOS

- Задача: Marine Debris (1) против размеченных остальных классов. Класс 0 — ignore; confidence 0 и нечисловые/недействительные спектры исключаются.
- Каналы: 11 Sentinel-2 каналов в порядке MARIDA; MADOS rhorc, без деления на 10000. Ближайший сосед при увеличении 20/60 м, как default у авторов. Исходные наименования классов MADOS сохраняются: class 6 — Oil Spill, НЕ MARIDA Clouds.
- Официальное разделение целыми Scene_N: 96 train, 36 validation, 42 test. Если найдутся одинаковые изображения между группами, весь связанный компонент переносится в наиболее защищённый split (test > val > train).
- Существенное ограничение: MADOS TIFF имеет фиктивную EPSG:4326 и единичную матрицу transform; даты/координаты в архиве не опубликованы. Нельзя доказать независимость MADOS от MARIDA по времени/географии. Проверяем точные совпадения 11-канальных размеченных спектров, исключаем целые MADOS-сцены с совпадениями при объединении. Это проверка известных дублей, а не доказательство отсутствия всех пересечений.
- Три фиксированные модели: существующий MARIDA RF с прежним порогом; MADOS-only RF; MARIDA-train + MADOS-train RF. RF: 125 деревьев, depth20, leaf2, balanced_subsample, confidence weights 1, 2/3, 1/3, seed42, 4 workers. Новые модели выбирают порог только по MADOS validation. Для MARIDA используется тот же выбранный порог; дополнительной настройки на MARIDA test нет.
- Сравнение на MADOS test и прежнем MARIDA test (теперь development benchmark). Совместное обучение и перенос — исследовательский результат с неразрешённой независимостью источников; не основание утверждать рост качества в Чёрном море. Основная самостоятельная проверка MADOS-only: изоляция по Scene_N, но соседние съёмки без metadata проверить невозможно.
- Метрики: precision, recall, F1, IoU, AP, ошибки по исходным классам. Доверительные интервалы и разности F1: paired bootstrap целыми сценами/группами, 1000 повторов, seed42. Никакого подбора параметров после test.

## PLP2019

Геометрическое сопоставление UAV-пикселя с ближайшим центром NetCDF в UTM35N, допуск 7.1 м. Дубликаты запрещены. Доля пластика = CP_Bags + CP_Bottles; тростник сохраняется отдельно. Полнота композиции = 100%. Для покрытий используется отдельная StandardScaler + Ridge(alpha=10), выход ограничен [0,100], leave-one-date-out; контроль — среднее только тренировочных дат. MAE в процентных пунктах, R². MARIDA rhorc RF не подаётся на rhos PLP. Этот маленький эксперимент не является калибровкой items/km².

## EMBLAS / T3

Сохраняются все 302 Monitoring Session ID, опубликованные счётчики, площади, ширина, длина, время без предположения UTC, 40 истинных нулей. Координаты не восстанавливаются из карт или соседних наблюдений. До проверки связи session_id ↔ coordinates таблица находится в pending; t3_eligible=False. Площадь не заменяется площадью спутникового пикселя или буфера. Опубликованная округлённая плотность и пересчёт N/A сохраняются отдельно.

## Дополнительная ablation ERA5 (до получения метрик)

74 события основного визуального профиля (S3 41, S4 33), исходные CV folds из EDA без пересоздания. ERA5 через Open-Meteo: nearest sea grid cell, hourly, UTC, предшествующий календарный день (24 часа). Это контекст до наблюдения, не восстановленное точное время наблюдения, не течение и не Stokes drift. Фиксированные RF log1p: 125 trees, depth5, leaf3, seed42, 4 workers; координаты + сезон sin/cos против тех же признаков + mean/max wind, mean u/v, precipitation. Контроль — train median. MAE/RMSE/R² в items/km² отдельно для каждого профиля. Paired bootstrap улучшения MAE по уже заданным группам, 1000 повторов. Тест исследовательский, окончательной новой независимой проверки не заменяет.
